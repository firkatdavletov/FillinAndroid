# Fillin

## О проекте

Fillin — Android-приложение для планирования семейного бюджета.

## Технологический стек

- UI: Jetpack Compose
- Архитектура проекта: feature-first, clean, data/domain/ui
- Сетевой клиент: Retrofit
- Dependency Injection: Koin
- Архитектура представления: MVVM
- Поток данных: Unidirectional Data Flow (UDF)

## Рекомендации для разработки

- Новую функциональность организовывать по feature-first подходу.
- UI реализовывать с помощью Jetpack Compose.
- Для сетевого взаимодействия использовать Retrofit.
- Зависимости предоставлять через Koin.
- Состояние экрана и пользовательские события обрабатывать в соответствии с MVVM и однонаправленным потоком данных.
