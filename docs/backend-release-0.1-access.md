# Доступ к облачным функциям Saldomi

Boolean-параметр Firebase Remote Config `remote_access` открывает облачные
функции для установки при `true`. При отсутствии параметра или Firebase
приложение открывается в локальном режиме. При старте процесса приложение
читает кеш и один раз запрашивает обновление с учётом интервала Firebase SDK.
При сбое загрузки действует последнее активированное значение.

При отзыве доступа приложение закрывает облачные экраны и останавливает
облачную синхронизацию. Локальные данные и очередь операций сохраняются.
FinanceConsultante проверяет Firebase-токен, членство и роль для защищённых
операций. Старые клиенты получают `OFFLINE_FREE` от `GET /api/v4/app/access`.

## Выпуск

1. В Firebase Console подготовить Boolean-параметр `remote_access` со значением
   по умолчанию `false`. Добавить условия `true` для нужных установок.
   Для точечного таргетинга условие `app.firebaseInstallationId` использует
   Firebase Installation ID (FID). SDK возвращает его через
   `FirebaseInstallations.getInstance().id`.
2. Выпустить FinanceConsultante с совместимым endpoint для старых клиентов.
3. Выпустить Android-клиент. Проверить загрузку флага на установках из целевой
   группы и локальный режим на остальных установках.
