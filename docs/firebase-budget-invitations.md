# T09 — семейное приглашение

## Доступно в Android

В «Облако» под списком бюджетов добавлен раздел «Семейный доступ». Он относится
к выбранному полностью подключённому облачному бюджету текущего Google-аккаунта.
OWNER может создать новый код, скопировать его, увидеть срок действия, обновить
статус и отозвать приглашение. MEMBER видит пояснение о правах владельца.
Локальный режим и незавершённый перенос бюджета не показывают эти действия.

Код действует 24 часа. Новый код заменяет прежний неиспользованный код только
этого бюджета. Операции требуют сети; локальная финансовая очередь не используется.
Ошибки приглашений не изменяют баланс, историю и синхронизацию бюджета.

Код хранится только в памяти ViewModel, без Room, SharedPreferences и SavedState.
При смене бюджета/аккаунта, выходе и истечении срока он удаляется из состояния.
При обычном повороте экрана сохраняется той же ViewModel. После остановки процесса
сервер возвращает только ID и срок действующего приглашения: его можно отозвать
или заменить, но прежний код нельзя получить повторно. Копирование использует
системный буфер обмена с флагом чувствительного содержимого.

Создание нового кода не является идемпотентным повтором: если ответ потерян,
прежний код больше не показывается, а повтор создаёт новый и отзывает предыдущий.
Отзыв по ID идемпотентен и не затрагивает код, созданный после этого ID.
Ответ прежнего бюджета после переключения не публикуется на новом экране.
Обновление Firebase ID token после 401 выполняется однократно для исходного пути.

## Серверный контракт

Нужен FinanceConsultante с миграцией V26 и включёнными MOBILE_API_ENABLED /
FIREBASE_AUTH_ENABLED. Новые credentials и переменные окружения не требуются.
Действуют существующие Firebase project ID и ADC вне репозитория. Production
не развёртывается автоматически.

- POST /api/v4/budgets/{budgetId}/invitations — создать код; ответ 200:
  `{id,budgetId,expiresAt,code}`.
- GET /api/v4/budgets/{budgetId}/invitations/current — актуальный статус;
  ответ 200 `{budgetId,current:{id,budgetId,expiresAt}}` или `{budgetId,current:null}`.
  Поля code в статусе нет.
- DELETE /api/v4/budgets/{budgetId}/invitations/{invitationId} — отзыв, ответ 204.

Все ответы помечены Cache-Control: no-store. Перед транзакцией сервер проверяет
Firebase ID token; внутри неё разрешает действия только активному OWNER по паре
проверенный UID / budgetId. MEMBER и посторонний UID получают 403, неверный токен — 401.
Старый статический токен к этим endpoints не допускается.

Код содержит 20 случайных Base32-символов, сгруппированных через дефис; SecureRandom
даёт 100 бит случайности. В firebase_budget_invitation хранится только SHA-256 хеш,
ID бюджета/владельца и timestamps. Plaintext возвращается один раз при создании.
Блокировка бюджета сериализует создание и отзыв; частичный уникальный индекс допускает
один неотозванный и неиспользованный код бюджета. Ошибка транзакции сохраняет прежнее
приглашение. Просроченное приглашение не возвращается как действующее, в том числе
точно на границе expiresAt. Начальные данные, членства и receipts сохраняются при V25→V26.

Принятие кода, создание MEMBER и расходование одноразового приглашения реализованы
в [T10](firebase-family-budget.md); для них нужен сервер с миграцией V27.

## Проверка установленной сборки

1. Войти через Google, открыть «Облако» и выбрать облачный бюджет владельца.
2. В «Семейный доступ» нажать «Создать новый код»: появляются код и время окончания.
3. Нажать «Скопировать код» и проверить вставку в выбранном пользователем приложении.
4. Создать новый код: старый становится отозванным. Отозвать новый — активного кода нет.
5. Создать код в первом бюджете, выбрать второй и создать другой. Статусы относятся
   к своим бюджетам; после переключения plaintext предыдущего кода скрыт.
6. Перезапустить приложение: виден статус, копирование прежнего кода недоступно,
   отзыв и создание нового работают. Выйти — семейный раздел скрыт.

Права MEMBER проверяются автоматическими фикстурами. Реальный вход в семейный бюджет
и полная проверка двумя аккаунтами описаны в [T10](firebase-family-budget.md). Автоматические тесты T09 используют
синтетические токены/данные; реальный Google и обновлённый тестовый сервер проверяются отдельно.
