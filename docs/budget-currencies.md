# Валюта бюджета

При создании локального или облачного бюджета доступны KZT, RUB, USD и EUR.
Новый бюджет по умолчанию создаётся в рублях. После обновления приложения старые
бюджеты и незавершённые запросы создания получают KZT.

В профиле откройте редактирование бюджета и выберите валюту. Подтверждение меняет
единицу учёта всех сумм. Например, баланс 1 000 ₸ становится 1 000 ₽.
Детали исторических валютных операций сохраняют исходную сумму и курс.

Владелец облачного бюджета может поменять валюту офлайн. Выбор сразу применяется
на устройстве и передаётся участникам при следующем обмене. Очередь хранится в Room
и повторяет исходный запрос после сбоя. При потере прав серверная валюта
восстанавливается. При нескольких изменениях применяется последняя принятая сервером
версия.

API v4 передаёт `currency` при создании и импорте. `PATCH /api/v4/budgets/{budgetId}`
принимает `requestId` и поля `name` и/или `currency`. Каталог и финансовый обмен
возвращают валюту и `currencyVersion`. Поля с историческим именем `amountKzt`
передают числовые значения в валюте бюджета.

Выпускать сначала FinanceConsultante с миграцией V34, затем Android у всех участников.
